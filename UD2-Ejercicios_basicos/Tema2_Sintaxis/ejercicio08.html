Ejercicio 8 – Pirámide de números 1, 22, 333...

Genera una pirámide: 1 / 22 / 333 / 4444 / 55555.

Qué se usa:

  • for anidados: el de fuera = filas, el de dentro = cuántas veces se repite
  • <br> para saltar de línea en la página
  • texto.repeat(n) (método de String)
  • acumular en una variable
