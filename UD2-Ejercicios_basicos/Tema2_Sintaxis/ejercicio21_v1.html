Ejercicio 21 · Versión 1 – Calculadora con botones

Calculadora con botones 0-9, + - * /, = y C. Cada pulsación muestra en un alert lo que llevamos ("34", "34 +", "34 + 7", "34 + 7 = 41"). Operación sin primer número o = sin operación completa: no hace nada. C reinicia.

Qué se usa:

  • variables globales (fuera de las funciones) para recordar el estado: num1, op, num2
  • concatenar dígitos como TEXTO ("3" + "4" = "34")
  • parseFloat() solo al calcular
  • return para salir sin hacer nada
  • onclick="funcion('valor')" pasando parámetros
  • switch para la operación
  • generar botones con document.write en un bucle
