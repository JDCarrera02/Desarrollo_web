Cada ejercicio tiene 3 versiones comentadas. En los ejercicios 1–19 al abrir la página te pregunta qué versión ejecutar (F5 para probar otra). El 20 y el 21 llevan botones, así que hay un archivo por versión. Para ver el código: clic derecho → Ver código fuente o ábrelo en VS Code.

Chuleta rápida

Entrada / salida 
let x = prompt("Pregunta", "valor por defecto"); // texto o null
alert("Mensaje");                 // solo aceptar
let ok = confirm("¿Seguro?");     // true / false
document.write("<p>Hola</p>");   // escribe HTML en la página
console.log(x);                   // a la consola (F12)
Convertir texto a número 
parseInt("12.7abc")  // 12  (entero, ignora lo de detrás)
parseFloat("12.7")   // 12.7
Number("12abc")      // NaN (más estricto)  · Number("") → 0
isNaN(x)             // true si NO es número
Number.isInteger(x)  // true si es entero
String(5) o 5 + ""   // número → texto
(3.14159).toFixed(2) // "3.14"
Trampas típicas 
"5" + 3    // "53"  (+ con texto concatena)
"5" - 3    // 2     (- * / convierten a número)
"10" < "9" // true  (compara textos letra a letra)
"7" == 7   // true  (== convierte el tipo)
"7" === 7  // false (=== compara tipo y valor)
-3 % 2     // -1    (usa Math.abs)
Condicionales 
if (a > b && c) {...} else if (a == b || !c) {...} else {...}
let t = (n % 2 == 0) ? "par" : "impar";
switch (op) {
  case "+": case "suma": r = a + b; break;
  default: r = null;
}
switch (true) { case n >= 0 && n < 10: ...; break; }
Bucles 
for (let i = 1; i <= 10; i++) {...}
for (let i = 1; i <= n; i += 2) {...}   // de 2 en 2
while (cond) {...}                       // puede no ejecutarse
do {...} while (cond);                   // al menos 1 vez
break;    // sale del bucle · continue; // salta a la siguiente vuelta
Texto (String) 
s.length  s.toUpperCase()  s.toLowerCase()  s.trim()
s.charAt(0)  s.charCodeAt(0)  s.indexOf("a")  // -1 si no está
s.includes("a")  s.startsWith("-")  "*".repeat(3) // "***"
`Hola ${nombre}`                          // plantilla
Math y arrays básicos 
Math.floor(3.9) // 3   Math.round  Math.ceil  Math.abs
Math.max(a, b)  Math.min(a, b)
Math.floor(Math.random() * (MAX - MIN + 1)) + MIN  // aleatorio entre MIN y MAX
let arr = []; arr.push(x); arr.length; arr.sort(); arr.join(", ");
arr.includes(x)
Funciones y botones 
function sumar(a, b) { return a + b; }
<button onclick="jugar()">Jugar</button>
<button onclick="numero('7')">7</button>
// document.write DESPUÉS de cargar la página la borra entera:
document.getElementById("id").innerHTML += "<p>...</p>";
