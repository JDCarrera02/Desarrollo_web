Ejercicio 17 – ¿Número, vocal, consonante, mayúscula u otro? (switch)

Dado un carácter, di si es número, vocal, consonante, si está en mayúsculas o si es otro. Usa switch case.

Qué se usa:

  • switch (true) con condiciones en los case
  • case seguidos sin break para agrupar (las vocales)
  • comparar caracteres: c >= "a" && c <= "z"
  • c === c.toUpperCase() para saber si está en mayúsculas
  • charCodeAt() da el código numérico del carácter
